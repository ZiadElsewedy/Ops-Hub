# OpsHub brand assets

Open `OpsHub Logo.dc.html` for the full identity sheet (lockup, icon, scale, palette, type).

## Files
- `logo/` — horizontal lockups: default (navy + teal), blue accent, 1-color navy, inverse for dark backgrounds.
- `icon/` — standalone icon, 64x64 viewBox: default, blue accent, 1-color navy, all-white, inverse.

## Colors
- Deep navy `#1B2A4A` — wordmark, nodes, connectors
- Hub core (accent): amber `#F59E0B` (current default). Alternates: teal `#00C9A7`, blue `#2563EB`
- Background: white `#FFFFFF` / off-white `#FBFBFC`

## Type
Space Grotesk — Semibold 600 ("Ops"), Medium 500 ("Hub"), tracking -0.035em.
The lockup SVGs use live text; convert to outlines before handing to print vendors, or use the identity sheet as reference.

## Usage
- Minimum icon size 20px; below 32px use the heavier-stroke rendering shown in section 03 of the sheet.
- Clear space around the lockup: half the icon height on all sides.
- Do not recolor the wordmark, add gradients or shadows, or separate the hub core from its nodes.
